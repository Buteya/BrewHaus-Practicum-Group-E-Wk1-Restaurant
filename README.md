# BrewHaus Restaurant

A modern restaurant landing page designed to showcase a premium dining experience. The site includes a hero section, brand story, menu categories, reservation call-to-action, and restaurant contact details.

## Project Overview

BrewHaus Restaurant is a static website built with HTML and CSS. It presents a warm, upscale restaurant identity with sections for:

- Home / hero introduction
- About the restaurant
- Interactive menu tabs for starters, mains, and desserts
- Reservation section
- Contact information and opening hours
